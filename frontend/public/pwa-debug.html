📋 iOS Share Sheet Troubleshooting

If PWA is installed but not in share sheet:
  1. Make sure you're using Safari (not Chrome/Firefox)
  2. Try uninstalling and reinstalling the PWA
  3. Check if the app supports the content type you're sharing
  4. Try sharing different types of content (URLs, text, images)
  5. Restart your device and try again
