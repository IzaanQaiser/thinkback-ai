🧠 Thinkback.ai — Full Phase Plan (June to September 2025)

⸻

🔹 Phase 1: MVP – Unified Smart Vault (🟢 In progress)

Goal: Launch a simple, working version that helps people stop losing saved content
	•	Save content from TikTok, IG, YouTube via paste/upload or basic share
	•	Scrape metadata + generate summaries with AI
	•	Categorize content into folders/tags
	•	Early user onboarding & dashboard

✅ Target Launch: Early July
🎯 Goal: First 250 active users + usable product

⸻

🔹 Phase 2: Native Integrations + Share Sheet

Goal: Make saving frictionless
	•	Chrome Extension (1-click save from web)
	•	Mobile Share Sheet support (save from any app via share)
	•	Autofill metadata/scraping during save flow

✅ Launch: Mid-July
🎯 Goal: Boost DAU and content volume (get to 1,000 users)

⸻

🔹 Phase 3: Viral Hook + Social Saving Layer

Goal: Make sharing and saving content social
	•	Public vaults: Users can share their saved “Collections” (e.g., “My top startup videos”)
	•	“Save from others” → Users can 1-click save from someone else’s collection
	•	Leaderboards or featured vaults (gamified exposure)
	•	Optional: @thinkback mention mechanic (e.g., tag to save content)

✅ Launch: Late July
🎯 Goal: 3,000 users via viral growth loops and organic sharing

⸻

🔹 Phase 4: Segmenting by Intent Type

Goal: Personalize saved content and retrieval
	•	Classify every saved item by intent:
	•	Actionable, Inspirational, Feel-good, Reflective
	•	Add “filter by intent” and “resurface based on intent” features
	•	Users can choose what type of content they want to recall

✅ Launch: Early August
🎯 Goal: Improve stickiness → Boost weekly retention

⸻

🔹 Phase 5: Conversational Memory Access (v1)

Goal: Let users talk to their content
	•	Build a chat interface (LLM + embeddings)
	•	Start with keyword matching + summaries (fake RAG if needed)
	•	Examples:
	•	“What did I save about motivation last week?”
	•	“Did I ever save anything about fasting?”

✅ Launch: Mid-August
🎯 Goal: Stickiness + press buzz + showcase AI core

⸻

🔹 Phase 6: Support Program Push + Microgrant Applications

Goal: Fundraise and get credibility
	•	Apply to:
	•	Velocity Fund / Velocity Microgrants
	•	Concept by UW
	•	Hack the North Techyon Grant
	•	Communitech Rev
	•	UWaterloo Co-op Innovation Fund
	•	Add pitch video + traction stats

✅ Ongoing from July 1
🎯 Goal: Raise $10k+ in non-dilutive capital + improve legitimacy

⸻

🔹 Phase 7: Custom AI Model (Prototype)

Goal: Go beyond scraping — understand content like a human
	•	Run Whisper + vision models to analyze video/audio
	•	Use outputs for richer summaries, emotion tagging, better search
	•	Use low-hanging batch inference first (not live yet)

✅ Prototype Start: August 20
🎯 Goal: Build credibility with investors and early power users

⸻

🔹 Phase 8: Global & Personal Context Awareness

Goal: Intelligent resurfacing at the right time
	•	Connect to public data APIs (news, market, etc.)
	•	Use saved content + external events to send smart nudges
e.g. “Remember this video about inflation-proof investing?”

✅ Launch: September
🎯 Goal: Boost re-engagement → 10k+ MAU

🔹 Phase 9: Journaling + Calendar Integration

Goal: Use emotional and time context to improve content recall
	•	Users can journal manually or with voice
	•	Calendar sync (Google Calendar first)
	•	System matches entries to emotional states or free time

✅ Launch: Late September
🎯 Goal: 15,000 active users + prepare for YC / Demo Day
